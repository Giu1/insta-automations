User data deletion

If you connected an Instagram account to Insta Automations (or you messaged/commented on an account that uses it), you can ask us to delete related data.

What we delete

  • Access tokens and brand connection for your Instagram account
  • Scheduled posts queued for that account
  • Stored comment IDs, message IDs, and sender IDs used for auto-replies

How to request deletion

  1. Email the app operator with subject Instagram data deletion.
  2. Include your Instagram username and, if you have it, the Instagram user id.
  3. We will delete stored records for that account and confirm by email.

You can also disconnect the app in Instagram: Settings → Website permissions / Apps and websites → remove this app.

This page satisfies Meta’s “User data deletion request URL” requirement.
