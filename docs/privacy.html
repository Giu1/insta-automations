Privacy Policy

Last updated: 16 September 2026

Insta Automations is a tool used by Marketer Milano to publish Instagram content, reply to comments, and reply to Instagram Direct messages after someone messages first. It uses Meta’s official Instagram APIs.

Data we process

  • Instagram professional account IDs and access tokens (stored as server secrets)
  • Scheduled post captions, media URLs, and publish times
  • Comment IDs and message IDs (to avoid duplicate replies)
  • Instagram-scoped sender IDs for people who message the business (24-hour auto-reply window)
  • Webhook payloads Meta sends to our server

How we use it

Only to operate the Instagram account you connect: publishing, comment replies, and user-initiated message replies. We do not sell personal data or use it for ads profiling.

Sharing

Data is sent to Meta/Instagram as required to provide the service. We do not share it with other third parties except hosting providers that run this app.

Retention

Duplicate-prevention records and scheduled posts are kept only as long as needed to run the service. You can request deletion at any time.

Your rights

To access or delete data this app stored about you, use the Data deletion page or email the operator of this app.
